# Task 2: Khởi tạo dự án

## Mục tiêu
- Thiết lập cấu trúc thư mục, môi trường và các dependencies cho dự án (dựa trên tài liệu `techstack.md`).

## Công việc chi tiết
1. **Backend**:
   - Khởi tạo dự án (ví dụ: `go mod init` với Golang).
   - Cài đặt các thư viện cần thiết (Router, ORM, JWT, Validation...).
   - Thiết lập cấu trúc thư mục (vd: `controllers`, `models`, `routes`, `services`, `configs`).
   - Cấu hình kết nối tới Database (PostgreSQL).
2. **Frontend** (optional):
   - Khởi tạo dự án React (Vite hoặc CRA).
   - Cài đặt thư viện (React Router, Axios, TailwindCSS...).
   - Thiết lập các thư mục (vd: `components`, `pages`, `services`, `utils`).
