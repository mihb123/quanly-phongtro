Upload ảnh CCCD chậm vì chặng từ trình duyệt lên Cloudflare: nhà mạng Việt Nam bị Cloudflare đưa tới colo ở Mỹ hoặc châu Âu và mất gói nặng. 3. Script triển khai: scripts/deploy/edge/

deploy-edge.sh install <ssh-host>            # cài/cập nhật edge + bật tunnel tới nó
deploy-edge.sh cert <ssh-host> <domain>...   # chờ DNS trỏ về edge, xin chứng chỉ, bật HTTPS
deploy-edge.sh status                        # tunnel nào đang chạy, domain trỏ về đâu
deploy-edge.sh remove <ssh-host>             # gỡ edge khỏi máy chủ, tắt tunnel

Trên máy edge (remote-setup.sh, chạy bằng root/sudo)

  • Cài nginx, certbot nếu thiếu (Debian/Ubuntu).
  • User qlpt-tunnel: không có shell, không đăng nhập bằng mật khẩu, key chỉ được mở đúng các cổng trong sites.conf. Cấu hình sshd nằm trong sshd_config.d/60-qlpt-tunnel.conf; script kiểm tra cấu hình này không ảnh hưởng tới user khác.
  • Site /etc/nginx/sites-available/qlpt-edge.conf: tự nhận ra SNI router (như trên ocl) hoặc nghe thẳng cổng 443. Có upstream keepalive, gzip, cache 1 năm cho /assets/, body tối đa 20MB, ghi đè CF-Connecting-IP.
  • Chạy nginx -t trước khi reload; nếu lỗi thì trả lại cấu hình cũ, nên không làm hỏng các site khác.
  • Chứng chỉ Let's Encrypt theo kiểu webroot; certbot.timer tự gia hạn rồi reload nginx.

Trên server nhà

  • Key riêng ~/.ssh/qlpt_tunnel_ed25519.
  • Systemd user unit dạng template qlpt-edge-tunnel@<host>, cấu hình ở ~/.config/qlpt-edge/<host>.env. Có thể chạy song song nhiều edge, nên chuyển máy edge không gây gián đoạn.
  • sites.conf: mỗi dòng domain cổng, hiện là quanly.ptro.site 9185 và pt.ptro.site 9180.
  • Frontend: imageCompression.ts dùng pool tối đa 3 worker (giới hạn theo số nhân CPU và RAM của máy); TenantEditModal.tsx khởi động sẵn pool khi bấm "Tải ảnh CCCD".

5. Chuyển domain và rollback

  1. Trong Cloudflare → DNS: xoá CNAME của domain, tạo bản ghi A trỏ IP edge (149.118.154.51), Proxy status DNS only.
  2. Chạy scripts/deploy/edge/deploy-edge.sh cert ocl <domain>. Lệnh tự chờ DNS cập nhật, xin chứng chỉ và bật HTTPS; khoảng gián đoạn chỉ vài giây.

Rollback về Cloudflare:

cloudflared tunnel route dns --overwrite-dns 8031e4bd-97d2-4847-a6d6-5c57b2d9475d <domain>

Chuyển sang máy edge khác: chạy deploy-edge.sh install <host-mới>, đổi DNS, chạy cert, rồi remove <host-cũ>. Lệnh remove từ chối chạy nếu vẫn còn domain trỏ về máy đó.

6. Đánh đổi

  • Domain đã chuyển không còn WAF, chống DDoS và cache ở edge của Cloudflare. IP của ocl bị lộ, còn IP nhà vẫn ẩn.
  • ocl là điểm lỗi đơn và đang chạy chung với mail và Nextcloud. Nếu ocl chết thì rollback DNS như ở mục 5.
  • Nginx 1.24 trên Ubuntu 24.04 không có HTTP/3; với RTT 48 ms thì không đáng kể (HTTP/3 chỉ giúp rõ khi đi Seattle).
  • Thời gian nén ảnh trên điện thoại cấu hình yếu sẽ dài hơn số đo trên máy chủ. Nên thử một lần trên điện thoại thật sau khi deploy.
