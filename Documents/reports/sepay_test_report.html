Lỗi phát hiện và đã sửa

Mức độVấn đề trước sửaCải thiện đã áp dụng
CaoĐối soát luôn gọi production host nên token Test Mode trả 401.Thêm environment typed; chọn cố định production/sandbox base URL và tương thích credential cũ.
CaoHMAC đúng có thể bị phát lại vô thời hạn.Parse timestamp và từ chối request lệch quá ±5 phút.
CaoWebhook không ràng buộc accountNumber với tài khoản manager.Từ chối payload gửi tới tài khoản khác trước khi tạo payment event.
Trung bìnhForm không có lựa chọn Live/Test Mode và phương thức auth rỗng gây select khó thao tác.Thêm select môi trường; HMAC là mặc định an toàn; validation hiển thị theo field.
Trung bìnhNgân hàng là ô nhập tự do nên có thể lưu tên không được SePay/VietQR hỗ trợ.Đổi sang Select gồm đúng 23 mục supported=true từ danh sách được tài liệu SePay tham chiếu; thêm validation phía form.
Trung bìnhTên chủ tài khoản nhập tay không được đối chiếu dù đã có API Token.Khi có token, backend chỉ chấp nhận tài khoản đã liên kết với đúng công ty/môi trường và lưu account_holder_name chuẩn từ API v2.
Trung bìnhSandbox trả trường active khác kiểu dữ liệu trong ví dụ tài liệu API v2.Model phản hồi chỉ giải mã ba trường cần thiết cho xác thực, tương thích Sandbox và Live mà không ép kiểu không cần thiết.
Trung bìnhNút xóa cấu hình thực thi ngay, dễ thao tác nhầm.Thêm AlertDialog xác nhận và mô tả ảnh hưởng tới QR active.
Trung bìnhForm/action chưa tối ưu touch và URL dài trên mobile.Touch target ≥44px, input 16px, action xếp dọc, URL min-width: 0, card không tràn ngang.
Trung bìnhHTTP client SePay không có test và coverage 0%.Thêm test routing sandbox/production, Bearer header, query, lỗi upstream/JSON/cancel.

Bằng chứng giao diện

Lệnh tái kiểm thử

Credential chỉ được truyền qua biến môi trường runtime; không có email, mật khẩu, API token hoặc HMAC secret nào được commit vào source/report.
cd frontend
pnpm test:frontend

SEPAY_APP_EMAIL='...' SEPAY_APP_PASSWORD='...' \
SEPAY_LOGIN_EMAIL='...' SEPAY_LOGIN_PASSWORD='...' \
pnpm test:e2e:sepay

cd ..
go test ./internal/service/payment ./internal/handler/payment ./internal/router

Ghi chú: Hướng dẫn đầy đủ nằm tại frontend/TESTING.md. Không chạy migrate, build hoặc deploy theo quy tắc dự án. Kịch bản settlement hóa đơn đủ/thiếu tiền được xác minh ở service test; browser E2E dùng giao dịch unmatched để không tạo hoặc thanh toán nhầm hóa đơn/người thuê thật.
